# Syed Maaz Ashraf - Portfolio

Eight chapters and 22 project detail views. Plain HTML, CSS and browser JavaScript.

## Deploy on Vercel

1. Download this ZIP from Drive.
2. Open https://vercel.com/drop and sign in to Vercel.
3. Upload this ZIP, or extract it and upload the folder containing index.html.
4. Choose your personal team and a project name, then select Deploy.
5. Open the live URL and test the Explore menu, project images and contact links.

No install, build command, environment variables, API keys or backend needed.
No vercel.json is required: index.html is at the root, and there is no public folder.
If importing through GitHub instead, choose Framework Preset Other, keep the build
command blank, and serve the repository root (.). Upload these files and assets
at the repository root, not inside another folder.

Navigation uses URL hashes, so no SPA path rewrites are needed.
The portfolio is static and has no server process to sleep. External project demos
are independent services and keep their own limits and availability.

## Editing

- index.html: shell and metadata
- style.css: responsive layout and motion
- app.js: navigation and page templates
- catalog.js: additional projects
- profile.js: experience, certification, campus and achievement records
- assets/: local optimized photos and screenshots

The certification page contains recovered, verified records, not a claim that the
full current LinkedIn certification list was accessible. Project detail pages state
known limits and whether a live demo or public source link was verified.
